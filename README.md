# 증권사 CMA 금리 비교

증권사 24곳의 CMA 금리를 **RP형 · 발행어음형 · MMW형 · MMF형 · 종금형** 전 유형으로 비교한 표입니다.

👉 **[비교표 보기](https://ttokjaetv.github.io/cma-compare/)**

---

## 이 표가 다루는 것

- 지금 새로 개설하는 **개인** CMA 계좌, 세전 연이율 기준
- 각 증권사 **공식 고시·공지**에서 직접 확인한 값
- 우대금리는 **적용 한도 금액을 함께** 표기 — 표시 금리만 옮기면 오보가 되는 경우가 많습니다
- 유형별 **예금자보호 여부**

## 다루지 않는 것

- 이미 보유 중인 계좌의 실제 적용 금리 (매수 시점 금리로 고정되는 구조가 많습니다)
- 법인 계좌, 세금 계산, 외화 RP·외화 CMA

---

## 알아두면 좋은 것

**CMA는 예금자보호가 되지 않습니다.** RP형·발행어음형·MMW형·MMF형 모두 비보호이고, 이 표에서 예외는 우리투자증권 종금형뿐입니다. (예금자보호 한도는 2025-09-01부터 1인당 1억원)

**금리는 금통위 직후에 한꺼번에 바뀝니다.** 2026년 7월에도 한국은행 기준금리 인상(7/16) → 한국증권금융 고시금리 변경(7/20 시행) → 전 증권사 CMA 금리 일제 인상(7/20~22) 순으로 움직였습니다. 표 상단의 **데이터 확인일**을 꼭 봐주세요.
